#炎孕的机翻总体还是比较有意思的:
1、通过本工具流导出双行文本后（name-msg-titles），我们需要处理以下注音格式:
＜●＞　＜●＞
去除[注释]：\[.+?\]替换为空
2、我们还需要处理以下的文本内代码:
    // 文本内控制符（各指令独立，可紧邻组合）:
    //   %f字体名;   — 切换字体，如 %f源ノ角ゴシックB;
    //   %fuser;     — 恢复默认字体
    //   #RRGGBBAA;  — 切换颜色，如 #00ff80c0;
    //   #;          — 恢复默认颜色
    //   %数字;      — 字号百分比，如 %150;（喊叫场景）
    //   $f.name;    — 运行时替换为玩家姓名
    //   \n          — 文本内换行
    //
    // 例: "はっけぇ～ん%f源ノ角ゴシックB;#00ff80c0;♥%fuser;#;"
    //   → 正文 → 切换字体 → 设颜色 → 显示♥ → 恢复字体 → 恢复颜色

%f源ノ角ゴシックB;
对于该字体控制符来说，我们直接删除即可
%fuser;
同理直接删除

#00ff80c0;
这个我们可以记录一下，然后写回，
但是理论上来说，text的代码，并不会执行，因此直接删除即可
#;
这个同理，删除

%数字;
这个就是放大的控制符了，还是需要保留一下的，需要注意
$f.name;
这个是自定义人名，需要保留，另外译后需要把文中的男主名换成这个，不然不能自定义人名，
但是对于name行的，我们保持原本即可，它是以default.tjs那边定义的占位符替换的

最好搜一下这俩:
♥
\r\n
%
