# BMP 与其他图片

这里放两类：

- 标准 `BMP`
- 不属于独立家族、但也应并入图片处理范围的其他格式

## BMP

魔数：

```text
42 4D
```

当前工具行为：

- 提取：直接转 PNG
- 回封：统一写成 24-bit Windows BMP

回封侧的关键点：

- 使用 GDI+ / `System.Drawing` 编码
- 强制 `PixelFormat.Format24bppRgb`
- 这是当前样本下最稳的保存方式
